## 需求 3：实体 / 事件编辑表单【P0】

### 3.0 业务目标

统一审核区抽屉、实体管理弹窗、事件管理弹窗的字段集，避免数据形态不一致。

> 字段命名以**后端真实字段**为准（snake_case），中文展示由前端做翻译；多语言字段统一处理（首期支持 zh / en / ar / tr / ru / zh-hk）。详见[附录 § 二、字段命名与状态规范](https://tapd.woa.com/tapd_fe/10153191/story/detail/1010153191134126457)。

---

### 3.1 实体字段集

对应接口：`POST /api/entities` / `PUT /api/entities/{id}`

| 字段（后端） | UI 控件 | 必填 | 校验 / 默认 | 说明 |
|---|---|---|---|---|
| entity_name | Input | ✓ | 不为空、≤ 50 字 | 实体名称（zh） |
| entity_name_* | Input × 5 | — | ≤ 50 字 | en/ar/tr/ru/zh_hk 多语言名称 |
| description | Textarea | — | ≤ 500 字 | 实体描述（zh） |
| description_* | Textarea × 5 | — | ≤ 500 字 | 多语言描述 |
| aliases | TagInput | — | 每个 ≤ 30 字 | 别名（zh），用于召回匹配 |
| aliases_* | TagInput × 5 | — | — | 多语言别名 |
| tags | Select（多选） | — | — | 标签数组，**取值为实体 ID**（is_category=true 的实体）；选项来自 `/api/tags` |
| is_category | Switch | — | 默认 false | 是否为分类实体（即可作为标签使用） |
| review_status | Radio | ✓ | 默认 pending | pending（待审核）/ approved（已通过）/ deleted（已拒绝） |
| parent_game_id | （隐藏） | ✓ | 来自顶部游戏切换 | 多游戏隔离必带 |

**多语言交互**：每个多语言字段在编辑表单内提供"语言切换 Tab"或可折叠的多语言区块，逐语言录入；未填写即留空。

### 3.2 事件字段集

对应接口：`POST /api/events` / `PUT /api/events/{id}`

| 字段（后端） | UI 控件 | 必填 | 校验 / 默认 | 说明 |
|---|---|---|---|---|
| event_name | Input | ✓ | 不为空、≤ 50 字 | 事件名称（zh） |
| event_name_* | Input × 5 | — | ≤ 50 字 | 多语言名称 |
| start_time | DatePicker | — | ISO 字符串 | 开始时间 |
| end_time | DatePicker | — | ISO 字符串、≥ start_time | 结束时间 |
| time_description | Input | — | ≤ 50 字 | 时间描述（"每周五至每周日"等） |
| time_description_* | Input × 5 | — | ≤ 50 字 | 多语言时间描述 |
| aliases | TagInput | — | — | 别名 |
| aliases_* | TagInput × 5 | — | — | 多语言别名 |
| tags | Select（多选） | — | — | 标签数组（实体 ID） |
| review_status | Radio | ✓ | 默认 pending | 同实体 |
| parent_game_id | （隐藏） | ✓ | 顶部游戏切换 | |

> ⚠️ **接口未定义 `event_type` 字段**——之前 v1.x 写的"活动 / 赛事 / 版本更新"分类首期不做。如需事件分类，可走 tags 实现。

### 3.4 与其它模块的关联

- 审核区抽屉里的"新发现实体 / 新发现事件"卡片表单与 §3.1/3.2 字段一致
- 实体 / 事件 / 事实管理页的"新建 / 编辑"弹窗使用同一字段集
- 事实编辑表单内的实体/事件选择器，**类型化召回**调用 `/api/entities/recall`，避免人工拼名称
- 入库时所有字段统一传给后端真实接口

---

### 3.5 多语言录入规范

- **录入策略**：默认中文（zh）必填，其余语言可选；保存时空字段不下发
- **导出策略**：`/api/facts/export?multilingual=true` 时输出全部 6 语言列；默认仅 zh
- **fallback 规则**：列表展示某条记录时，先查当前语言，缺失则回退中文
- **首期范围**：6 种语言（zh / en / ar / tr / ru / zh-hk）；UI 提供顶部全局语言切换 + 编辑表单内的多语言面板
